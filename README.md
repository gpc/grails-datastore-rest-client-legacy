# Grails Datastore Rest Client Legacy

[Apache Grails][Grails] is a framework used to build web applications with the [Apache Groovy][Groovy] programming language. This project provides a forward port of grails-datastore-rest-client 

[Grails]: http://grails.org/
[Groovy]: http://groovy-lang.org/

## Installation 

```groovy
dependencies {
    implementation 'io.github.gpc:grails-datastore-rest-client-legacy:7.0.0' // Or latest version
}
```
